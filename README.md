📡 Redirecionador Dinâmico de Tags NFC (Hub Educacional)Sistema leve, gratuito e sem servidor (serverless) para gerenciar ações interativas em tags NFC físicas espalhadas por ambientes educacionais e corporativos (auditórios, salas de docentes, laboratórios e eventos).Em vez de regravar fisicamente dezenas de adesivos NFC a cada novo evento, cada tag aponta permanentemente para um identificador único (ex: ?id=auditorio), enquanto o destino final (Viva Engage, Microsoft Forms, Mentimeter, vídeos, etc.) é controlado em tempo real por uma planilha no Google Sheets.🎯 Problema vs. SoluçãoO Problema: Tags NFC gravadas com links diretos exigem regravação manual presencial sempre que a atividade muda, inviabilizando o uso recorrente em eventos, reuniões pedagógicas e dinâmicas de integração.A Solução: Centralização do roteamento. A equipe técnica configura o sistema uma única vez, e coordenadores ou organizadores de eventos alteram os links de destino diretamente em uma planilha compartilhada, sem precisar de conhecimentos em programação.🏗️ Como Funciona[Tag NFC Física] ──▶ [GitHub Pages (index.html)] ──▶ [Google Sheets (CSV)] ──▶ [Destino Final]
  (?id=auditorio)         Lê o parâmetro ID             Consulta URL ativa        (Engage / Forms)
Tag Física: Possui uma URL fixa com um parâmetro de identificação (https://seu-usuario.github.io/seu-repo/?id=auditorio) e trava de leitura (Read-Only).Página Intermediária (index.html): Lê o parâmetro id da URL, consulta a planilha pública do Google Sheets em tempo real (com prevenção de cache) e executa o redirecionamento imediato.Painel de Controle (Google Sheets): Tabela simples onde cada linha associa um id físico a uma url ativa.🚀 Guia de Instalação e Configuração1. Configurar o Google Sheets (Painel do Coordenador)Crie uma nova planilha no Google Sheets.Configure o cabeçalho na Linha 1 exatamente com os seguintes nomes:Coluna A (id): Identificador único do local/tag (sem espaços ou acentos).Coluna B (url): Link completo de destino para onde o usuário será enviado.Coluna C (descricao): (Opcional) Referência visual do local físico para facilitar a gestão.idurldescricaoauditoriohttps://engage.cloud.microsoft/...Poltronas do Auditório Principalsala-docenteshttps://forms.office.com/...Mesa da Sala dos Professorespadraohttps://www.sp.senac.brLink de segurança (Fallback)Publique a planilha na web:Acesse Arquivo > Compartilhar > Publicar na web.Selecione a aba específica da planilha (ex: Página1) e escolha o formato Valores separados por vírgula (.csv).Clique em Publicar e copie o link gerado.(Recomendado) Proteja a Coluna A (Dados > Proteger páginas e intervalos) para que os editores da planilha alterem apenas os links da Coluna B, preservando os IDs gravados nas tags.2. Configurar o Código e Hospedar no GitHub PagesFaça um fork ou clone este repositório.Abra o arquivo index.html e localize as constantes de configuração no bloco <script>:// Cole o link CSV publicado no Passo 1
const CSV_URL = "COLE_AQUI_O_SEU_LINK_CSV_DO_GOOGLE_SHEETS";

Faça o commit e push da alteração para o seu repositório.Ative o GitHub Pages:Vá em Settings > Pages no repositório.Em Build and deployment, selecione a branch main (pasta /root) e clique em Save.Anote a URL pública gerada (ex: https://usuario.github.io/nfc-hub/).3. Gravar e Proteger as Tags NFCUtilize tags compatíveis com NDEF (recomendado: NTAG213 para URLs curtas/médias ou NTAG215).Instale um aplicativo gravador de NFC no smartphone (ex: NFC Tools para Android ou iOS).Acesse Gravar > Adicionar um registro > URL / URI.Insira a URL do seu GitHub Pages acompanhada do parâmetro ?id= correspondente ao local:Exemplo Auditório: https://usuario.github.io/nfc-hub/?id=auditorioExemplo Sala dos Docentes: https://usuario.github.io/nfc-hub/?id=sala-docentesAproxime o celular da tag para gravar.(Importante) No aplicativo, acesse a aba Outros > Bloquear tag (ou defina uma senha) para impedir que terceiros sobrescrevam o link da tag física.📋 Guia Rápido para Coordenadores (Operação no Dia a Dia)Para alterar a ação de qualquer tag antes de uma reunião ou evento:Copie o link da atividade desejada (postagem no Viva Engage, formulário de presença, quiz, etc.).Abra a planilha compartilhada no Google Sheets.Localize a linha referente ao ambiente (ex: auditorio) e cole o novo link na Coluna B (url).Aguarde cerca de 1 a 2 minutos (tempo de propagação do Google Sheets) e teste aproximando um celular da tag.💡 Exemplos de Uso InstitucionalEventos e Reuniões Pedagógicas: Check-in fotográfico no Viva Engage ao chegar no auditório;
